# KoreaEventList

대한민국 정식 행정경계 지도(1단계 17개 시·도 ↔ 2단계 250개 시·군·구 드릴다운)를 기반으로 **공공데이터포털(`KorService2` v4.4)**의 행사·축제 데이터와 **전국 267개 광역·기초지자체 공식 홍보 페이지**의 상세 정보를 주최기관 힌트(`sponsor1`, `sponsor2`, `telname`)로 매칭·요약하여 제공하는 웹 애플리케이션입니다.

## 주요 기능
- **정식 2단계 행정경계 지도**: 대한민국 17개 광역자치단체 및 전국 250개 시·군·구(창원 5개 구 등 일반구 포함) 정식 GeoJSON 폴리곤 지도 및 Leaflet GPS 마커 지도
- **공공데이터포털 `KorService2` v4.4 연동**: 법정동 코드(`lDongRegnCd`, `lDongSignguCd`) 및 신분류체계(`EV01` 축제, `EV02` 공연, `EV03` 행사·전시) 기준 실시간 조회 (`JSON` + `XML` 하이브리드 파서 지원)
- **전국 1·2단계 267개 지자체 행정·홍보 주소 마스터 DB**: 주최기관 힌트 기반 동일 이벤트 탐색·요약 및 별도 홍보 링크 결합
